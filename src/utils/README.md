# K-POP UNITED 🎵

The Ultimate K-Pop Community Platform

## 🚀 Fonctionnalités

- 🔐 Authentification (Email/Password + Google OAuth)
- 📝 Création et partage de posts
- 💬 Messagerie en temps réel
- 📸 Stories éphémères
- 🎫 Événements K-Pop
- 👥 Groupes et communautés
- 🔔 Notifications en temps réel
- 🌙 Mode sombre / clair
- 📱 Responsive mobile

## 🛠️ Technologies

- **Frontend**: React 18 + TypeScript
- **Backend**: Firebase (Auth, Firestore, Storage)
- **CSS**: Vanilla CSS avec animations
- **Build**: Vite

## 📦 Installation

\\\ash
git clone https://github.com/yourusername/kpop-united.git
cd kpop-united
npm install
cp .env.example .env
npm run dev
\\\

## 🔧 Configuration

### Variables d'environnement

Créez un fichier \.env\ à la racine du projet.

### Configuration Firebase

1. Créez un projet sur [Firebase Console](https://console.firebase.google.com/)
2. Activez Authentication, Firestore et Storage

### Configuration Google OAuth

1. Allez sur [Google Cloud Console](https://console.cloud.google.com/)
2. Créez un OAuth Client ID

## 🚀 Déploiement

\\\ash
npm install -g firebase-tools
firebase login
firebase init
npm run deploy
\\\
